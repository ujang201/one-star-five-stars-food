An alien tourist gives planet Earth a one-star review — and still can't help complimenting the food. `main.ts` deterministically writes one sentence (under 200 characters) to `/output/entry.txt`:

> One star: Earth charged me rent for breathing, the Wi-Fi demanded my soul, but the street tacos were so good I considered applying for citizenship.

## Run

```sh
node main.ts
```

This writes the review to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). No randomness, no clock, no network, no input — the output is byte-identical on every run.
